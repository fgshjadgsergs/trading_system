## Этап 3 — калибровка и валидация (самое сложное; не спешим)

_Статус: весь инструментарий этапа 3 реализован в `trading_system/calibration/` и проверен на синтетике с известной истиной (генератор позиций с заданным распределением плеч → ликвидации по формуле биржи). Содержательные выводы — только после Gate 1, на живых данных; галочки ниже означают «механика готова и проверена», а не «эффект доказан на рынке»._

### 3.1 Event studies — до всякой стратегии
- [x] P(разворот в пределах k·ATR) после касания пула топ-децили vs базовая частота — `calibration/event_studies.py` (проверено на синтетике: плановый эффект ловится, нулевой — нет)
- [x] «Магнит»: P(дойти до пула на расстоянии d за время T) — там же, кривая по бакетам d
- [x] Поведение цены в LVN — форвард-статистика входов в LVN vs остальное
- [x] Значимость бутстрепом с поправкой на пересекающиеся события; все графики — seaborn с доверительными интервалами — блочный бутстреп с кластеризацией пересечений; `viz.event_study_plot`
- [ ] Если эффекта нет — стоп, возврат к модели карты. Это дешёвый выход, а не провал — _решается только на живых данных после Gate 1_

### 3.2 Веса плеч: статика → динамика (заготовка будущей ML-модели)
- [x] Ступень 1 — статика: глобальные w на трейн-окне. Метрика — capture rate: доля реальных ликвидаций (forceOrder + liquidationSnapshot) в топ-дециле ячеек по теплу — `calibration/weights.py: StaticWeightCalibrator, capture_rate`
- [x] Наивный бейзлайн (круглые числа + свежие экстремумы) обязан быть побит — иначе карта не работает — `naive_baseline_heat`; на синтетике калиброванная карта бьёт бейзлайн (0.25 vs 0.20), критерий вшит в тесты
- [x] Ступень 2 — скользящая: еженедельная пере-калибровка w на трейлинг-окне, walk-forward — `RollingCalibrator`
- [x] Ступень 3 — контекстная: w(context) из мульти-ТФ фич M3. Модель: softmax-регрессия (numpy, L2-регуляризация), предсказывающая распределение плеч — `ContextualWeights`
- [x] Гипотезы проверяем, не постулируем — на синтетике с контекстно-зависимой смесью плеч контекстная ступень выигрывает и выбирается; на контекстно-свободной — компаратор корректно откатывается к статике (тест)
- [x] Сравнение трёх ступеней только по OOS capture rate; усложнение без прироста откатываем — `compare_ladder` с правилом «простейшая в допуске»

### 3.3 Walk-forward стратегии
- [x] Калибровка на скользящем окне, тест строго out-of-sample, эмбарго-зазор между train и test — `calibration/walkforward.py` (сплиттер с эмбарго, canary-тест на утечку)
- [x] Прогон по режимам (тренд/пила, высокая/низкая вола) и по трём символам — каузальные режимные метки (абсолютный порог тренда, экспандирующая медиана волы), мульти-символьный харнесс
- [ ] Минимум параметров; каждый новый оправдывается приростом OOS, не in-sample — _дисциплина ведения исследований на живых данных_

**Gate A:** карта бьёт наивный бейзлайн по capture rate. — ⏳ метрика и харнесс готовы; вердикт после Gate 1
**Gate B:** event-эффект статистически значим и переживает оценку издержек. — ⏳
**Gate C:** положительный OOS-результат после комиссий и проскальзывания при вменяемой просадке. — ⏳
